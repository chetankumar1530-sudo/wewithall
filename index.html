Curriculum

Complete AI/ML Syllabus

6-month intensive program covering everything from Python basics to cutting-edge Generative AI. Updated monthly with the latest industry trends.

Python Programming

  • Data types, control flow, functions, OOP
  • List comprehensions, lambda functions, decorators
  • File handling, exception handling, modules & packages
  • Working with APIs, JSON, and web scraping (BeautifulSoup, Scrapy)

Data Science Libraries

  • NumPy: Arrays, vectorization, broadcasting
  • Pandas: DataFrames, data cleaning, merging, groupby
  • Matplotlib & Seaborn: Data visualization, plots, dashboards
  • Plotly: Interactive visualizations and dashboards

Statistics & Mathematics

  • Descriptive & inferential statistics
  • Probability distributions, hypothesis testing
  • Linear algebra: vectors, matrices, eigenvalues
  • Calculus: derivatives, gradients, optimization

SQL & Databases

  • SQL queries, joins, subqueries, window functions
  • PostgreSQL, MySQL, MongoDB basics
  • Database design and normalization

Supervised Learning

  • Linear Regression, Polynomial Regression
  • Logistic Regression, Decision Trees, Random Forest
  • SVM, KNN, Naive Bayes
  • Gradient Boosting: XGBoost, LightGBM, CatBoost
  • Ensemble methods: Bagging, Boosting, Stacking

Unsupervised Learning

  • K-Means, Hierarchical Clustering, DBSCAN
  • PCA, t-SNE, UMAP for dimensionality reduction
  • Anomaly detection: Isolation Forest, LOF
  • Association Rules: Apriori, FP-Growth

Feature Engineering

  • Feature selection: RFE, feature importance, correlation
  • Feature extraction: PCA, LDA, autoencoders
  • Handling missing data, outliers, imbalanced datasets
  • Cross-validation, hyperparameter tuning (GridSearch, Optuna)

Model Deployment

  • MLflow for experiment tracking
  • Model serialization: Pickle, Joblib, ONNX
  • Building REST APIs with FastAPI
  • Docker containerization for ML models

Neural Network Fundamentals

  • Perceptrons, activation functions, backpropagation
  • TensorFlow 2.x & Keras, PyTorch
  • Optimizers: SGD, Adam, RMSprop, AdamW
  • Batch normalization, dropout, weight initialization
  • Transfer learning & fine-tuning pre-trained models

CNN - Computer Vision

  • CNN architectures: LeNet, AlexNet, VGG, ResNet, Inception
  • Object detection: YOLOv8, Faster R-CNN, SSD
  • Image segmentation: U-Net, Mask R-CNN
  • GANs: DCGAN, StyleGAN, CycleGAN
  • Vision Transformers (ViT), Stable Diffusion basics

RNN & Sequence Models

  • RNN, LSTM, GRU architectures
  • Bidirectional RNNs, stacked LSTMs
  • Time series forecasting with deep learning
  • Attention mechanisms, seq2seq models

Traditional NLP

  • Text preprocessing: tokenization, stemming, lemmatization
  • Word embeddings: Word2Vec, GloVe, FastText
  • TF-IDF, Bag of Words, N-grams
  • Named Entity Recognition (NER), POS tagging
  • Sentiment analysis, text classification

Transformers & LLMs

  • Transformer architecture deep dive
  • BERT, RoBERTa, DistilBERT for understanding
  • GPT-3.5, GPT-4, Claude, Gemini architecture
  • Fine-tuning LLMs with LoRA, QLoRA
  • Prompt engineering: Chain-of-Thought, Few-shot, RAG

Advanced NLP Applications

  • Building chatbots with LangChain & LlamaIndex
  • Vector databases: Pinecone, Weaviate, ChromaDB
  • Semantic search & document Q&A systems
  • Text summarization, translation, text generation
  • Hugging Face ecosystem: Transformers, Datasets, Spaces

Generative AI

  • Text-to-image, image-to-image, inpainting

  • Music generation: MusicLM, AudioCraft

AI Agents & Autonomous Systems

  • AutoGPT, BabyAGI, CrewAI frameworks

  • Tool use, function calling, API integration
  • Building autonomous AI workflows
  • Agentic RAG: Advanced retrieval augmented generation
